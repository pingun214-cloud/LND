Modulo de lenguaje de marcas

Profesor: Jose Antonio Bonilla Muñoz

Aprende a construir páginas web desde su estructura hasta su comportamiento utilizando HTML, CSS, Responsive Web Design y JavaScript.

¿Qué es lenguaje de marcas?

Un lenguaje de marcas es un lenguaje de programación utilizado para definir la estructura y el contenido de documentos web.
