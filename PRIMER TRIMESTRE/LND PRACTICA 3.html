Servicios Informáticos ASIR

En esta práctica habablamos sobre los catálogo de servicios técnicos especializados en administración de sistemas y redes informáticas.

Indice de servicios

  • Administración de Servidores
  • Gestión de Redes e Infraestructura
  • Seguridad Informática
  • Soporte Técnico y Mantenimiento

1. Administración de Servidores

Configuración, despliegue y mantenimiento de servidores Linux y Windows Server para entornos corporativos.

Sistemas operativos gestionados:

  • Distribuciones Linux (Debian, Ubuntu Server, Red Hat)
  • Windows Server (Active Directory, DNS, DHCP)
  • Hardening y puesta en marcha de los servicios.

2. Gestión de Redes e Infraestructura

Diseño, segmentación y optimización de redes de comunicaciones locales y de área extensa.

Tecnologías y servicios:

  1. Subnetting y direccionamiento IP (VLSM / CIDR)
  2. Configuración de routers, switches y VLANs
  3. Interconexión de sedes mediante túneles VPN

3. Seguridad Informática

Protección perimetral, políticas de acceso y planes de recuperación para salvaguardar la información de la empresa.

Áreas clave:

  • Configuración de firewalls y reglas de filtrado
  • Gestión de políticas de copias de seguridad (Regla 3-2-1)
  • Actualizaciones de parches de seguridad

4. Soporte Técnico y Mantenimiento

Asistencia técnica integral tanto de forma presencial como remota a usuarios y estaciones de trabajo.

Tareas de mantenimiento:

  1. Instalación y actualización de software ofimático y corporativo
  2. Diagnóstico y sustitución de hardware dañado
  3. Gestión del inventario de equipos
